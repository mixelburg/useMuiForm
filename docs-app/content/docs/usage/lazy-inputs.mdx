# Lazy Inputs

Lazy inputs (also known as uncontrolled inputs) can improve performance by reducing re-renders. Instead of updating state on every keystroke, lazy inputs only update state when the field loses focus (onBlur).

## What are Lazy Inputs?

By default, useMuiForm uses **controlled inputs** - the form state updates on every change, causing a re-render.

With **lazy inputs**, the state only updates when:
- The field loses focus (blur event)
- `forceValidate()` is called

This can significantly improve performance for forms with many fields or complex validation logic.

## Enabling Lazy Mode

### Per Field

Enable lazy mode for individual fields:

```tsx
<TextField
  label="Email"
  {...register('email', {
    required: true,
    lazy: true
  })}
/>
```

### Globally via Config

Set lazy mode as the default for all fields:

```tsx
import { UseMuiFormConfigProvider } from 'usemuiform'

<UseMuiFormConfigProvider config={{
  defaultOpts: {
    lazy: true
  }
}}>
  <App />
</UseMuiFormConfigProvider>
```

### Per Form

Configure lazy mode at the form level:

```tsx
const form = useMuiForm({
  defaultValues: { email: '', name: '' },
  config: {
    defaultOpts: {
      lazy: true
    }
  }
})
```

## When to Use Lazy Inputs

### ✅ Good Use Cases

- **Large forms** with many fields
- **Complex validation** that's expensive to run
- **Forms with derived state** that causes cascading updates
- **Search fields** where you don't need real-time feedback

### ❌ Avoid When

- You need **real-time validation feedback**
- Implementing **dependent fields** that update based on other field values
- Building **dynamic forms** where fields appear/disappear based on values

## Validation with Lazy Inputs

Validation still works with lazy inputs, but timing differs:

```tsx
import type { ValidateFunc } from 'usemuiform'

const emailValidator: ValidateFunc<string, FormState> = (value) => {
  if (!value.includes('@')) return 'Invalid email'
  return true
}

<TextField
  label="Email"
  {...register('email', {
    required: true,
    lazy: true,
    validate: emailValidator
  })}
/>
```

The validation will run:
- When the field loses focus (onBlur)
- When `forceValidate()` is called

## Mixing Controlled and Lazy Inputs

You can mix both types in the same form:

```tsx
const { register } = useMuiForm<FormState>({
  defaultValues: { search: '', email: '', role: '' }
})

// Controlled - updates immediately
<TextField
  label="Search"
  {...register('search', { lazy: false })}
/>

// Lazy - updates on blur
<TextField
  label="Email"
  {...register('email', { lazy: true })}
/>

// Uses default from config
<TextField
  label="Role"
  {...register('role')}
/>
```

## Complete Example

```tsx
import { useMuiForm, UseMuiFormConfigProvider } from 'usemuiform'
import { TextField, Button } from '@mui/material'

type FormState = {
  firstName: string
  lastName: string
  email: string
  bio: string
}

// Option 1: Global configuration
export function AppWithGlobalLazy() {
  return (
    <UseMuiFormConfigProvider config={{
      defaultOpts: { lazy: true }
    }}>
      <MyForm />
    </UseMuiFormConfigProvider>
  )
}

// Option 2: Form-level configuration
export function MyForm() {
  const { state, register, forceValidate } = useMuiForm<FormState>({
    defaultValues: {
      firstName: '',
      lastName: '',
      email: '',
      bio: ''
    },
    config: {
      defaultOpts: {
        lazy: true  // All fields are lazy by default
      }
    }
  })

  const handleSubmit = () => {
    if (forceValidate()) {
      console.log('Submitted:', state)
    }
  }

  return (
    <div>
      {/* These inherit lazy: true from config */}
      <TextField
        label="First Name"
        {...register('firstName', { required: true })}
        fullWidth
      />
      <TextField
        label="Last Name"
        {...register('lastName', { required: true })}
        fullWidth
      />

      {/* Override to use controlled mode */}
      <TextField
        label="Email"
        {...register('email', {
          required: true,
          lazy: false  // This field updates immediately
        })}
        fullWidth
      />

      {/* Lazy multiline field */}
      <TextField
        label="Bio"
        multiline
        rows={4}
        {...register('bio', { lazy: true })}
        fullWidth
      />

      <Button variant="contained" onClick={handleSubmit}>
        Submit
      </Button>
    </div>
  )
}
```

## Performance Comparison

```tsx
// ❌ Without lazy - re-renders on every keystroke
const form1 = useMuiForm<{ description: string }>({
  defaultValues: { description: '' }
})
// Typing 100 characters = 100 re-renders

// ✅ With lazy - re-renders only on blur
const form2 = useMuiForm<{ description: string }>({
  defaultValues: { description: '' },
  config: { defaultOpts: { lazy: true } }
})
// Typing 100 characters = 1 re-render (on blur)
```
